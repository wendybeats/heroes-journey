# 02 — Core User Flows

## First session
1. App opens into story world, not a utilitarian dashboard.
2. Character wakes in a strange digital world.
3. Character asks the player to help identify them.
4. User supplies:
   - name
   - base body presentation
   - skin tone
   - hair style/color
5. App explains only the minimum premise: real-world activity helps the character grow.
6. User may connect Apple Health.
7. User chooses or confirms a few common activities.
8. If recent eligible activity exists, show it and grant first progression immediately.
9. Otherwise guide user into a simple manual log or first workout.
10. Show first meaningful reward and teaser of Level 5 evolution.
11. Offer account creation if user entered as guest.

## Daily return
Home should feel Tamagotchi-like:
- character centered in world backdrop
- current level / concise progress
- quick log action
- today's activity summary
- one next-goal teaser
- lightweight story/world reaction

## Manual activity
1. Tap Log.
2. Show recent/frequent activities first.
3. Search if needed.
4. Enter duration.
5. Complete.
6. Show concise game reward.

Target: common manual activity should take under ~10 seconds.

## Strength workout
1. Start from routine/template or blank workout.
2. Exercises show previous performance.
3. Add/edit sets, reps, weight.
4. Optional rest timer may be added if it does not threaten scope.
5. Finish workout.
6. Persist structured workout.
7. Detect PRs.
8. Convert activity into progression.
9. Show 2–4 second celebratory reward moment.

## Reward moment
Keep concise:
- XP gained
- Attribute gains
- PR / unlock if applicable
- short character reaction/animation
- progress toward next major milestone

Avoid turning every activity into a long interruption.
